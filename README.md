# Source and dependencies

The implementation developed for this entry is released under the MIT License below.
Pre-existing dependencies retain their own licenses.

The image uses Python 3.13 and SQLGlot at commit
eb11aec4be8cb2122afe713a4816662c3f0fb2fa. Its test dependencies include
pytest, pytest-xdist, pytest-timeout, DuckDB, NumPy and pandas. The complete
pinned dependency list is in requirements.lock inside app.tar.gz.
The bundled maps were produced from the pinned upstream source and tests.
The source archive also contains the build commands and implementation.
